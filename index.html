Что следует из выбранных данных

Источник: UCI · Student Performance, Cortez, P. (2008), DOI: 10.24432/C5TG7T · CC BY 4.0. Файл student-mat.csv, 395 учеников. Это историческая выборка, не данные за 2026 год.

Поля и расчёты

G1 — оценка первого периода, G2 — второго, G3 — итоговая годовая оценка. Изменение = G3 − G1. Среднее и медиана рассчитываются отдельно; медиана для чётной выборки — среднее двух центральных значений.

Доли считаются от числа выбранных учеников; разность долей указана в процентных пунктах. Порог 10 делит шкалу на две группы для анализа. Нулевые оценки сохранены. Каждый ученик один раз учтён на каждом этапе Санкея; две пары переходов не суммируются как число учеников.

Состав группы фиксируется общими фильтрами для всех трёх этапов. Фильтр по итогу или изменению задаёт условную выборку. Разница между группами не доказывает причинного влияния школы или пола. ИИ использован для разработки визуализации и проверки расчётов; значения взяты из UCI.
